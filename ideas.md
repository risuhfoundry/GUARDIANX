# GUARDIAN X — Design Direction

## Direction

The user selected a **clean dark minimal professional UI** for a serious modern school system. Use modern enterprise SaaS quality and restraint as a quality reference, without copying Linear, Vercel, or Raycast. Do not turn the product into cyberpunk or make the interface look like security software.

## Design movement and core principles

A calm, precise operations interface: low-noise surfaces, compact hierarchy, generous enough spacing for legibility, consistent control sizes, clear keyboard focus, and reusable components. Prefer quiet borders and typography over decorative effects. The design should feel dependable, respectful, and practical for school staff.

## Color philosophy

- Background: `#0B0C0E`
- Sidebar: `#0D0F12`
- Surface: `#131519`
- Elevated surface: `#181A1F`
- Border: `#24272D`
- Primary text: `#F5F5F5`
- Secondary text: `#9B9FA8`
- Muted text: `#666B75`
- Primary accent: `#5B7CFF`, used sparingly for primary emphasis, selected navigation and focus.
- Success, warning, error and pending states use muted, low-saturation tones.

Avoid broad blue fills, neon, glow, huge gradients, excessive glass effects, RGB, HUD/hacker/circuit motifs, holograms, gaming references, and futuristic security graphics.

## Layout paradigm and signature elements

Desktop uses a compact, collapsible left navigation rail and a flexible main surface. Tablet and mobile reflow rather than compressing desktop; navigation can become a drawer and content samples can stack. Use quiet one-pixel borders, clear surface separation, concise titles, and compact wordmark placement. Signature identity is the simple “GUARDIAN X” wordmark and a flat, geometric open-path/open-door mark suggesting a clear, safe passage—not a shield or biometric scanner.

## Interaction philosophy and motion

Make state and focus obvious but understated. Use native semantic controls, explicit labels, accessible dialog behavior, visible keyboard focus, and clear active/hover states. Motion is short and subtle, and should respect reduced-motion preferences. No simulated biometric, dismissal approval, API, or data workflow behavior in this foundation stage.

## Typography system

Use Inter (self-hosted where possible), with system sans-serif fallbacks. Keep body copy readable and precise; use restrained heading sizes, consistent weights, tabular numerals when useful, and secondary/muted text only for supporting information.

## Brand essence, voice, and wordmark

Professional, calm, clear, school-centered, and unobtrusive. Use “GUARDIAN X” as the wordmark; “Student Dismissal System” may appear as a small descriptor when helpful. Do not add a complicated shield illustration or glowing brand treatment.

## Project icon

Create an opaque 1:1 square icon with full-bleed dark background and a broad, flat, minimal open-path/open-door symbol in the brand colors. Ensure it reads at small sizes without small details; reuse this asset for the site favicon and platform project logo metadata.
